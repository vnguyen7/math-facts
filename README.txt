MATH ADVENTURE — INSTALL ON IPAD

1. Deploy all files and the icons folder together to Vercel (or another HTTPS static web host).
2. Open the published HTTPS website in Safari on your iPad.
3. Tap Share > Add to Home Screen > Add (choose Open as Web App if offered).
4. Launch Math Adventure from your Home Screen.
5. Open the app once while online before testing offline mode.

NOTE: Opening index.html directly as a file will not install the offline service worker.
Your progress is stored in this browser/device, not synced between devices.
