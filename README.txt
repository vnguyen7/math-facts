Math Adventure v6 — iPad PWA with progress tracking. Deploy ALL files together to HTTPS hosting. Open in Safari, Share > Add to Home Screen. Use Parent Dashboard for profiles, scores, mastery, missed questions, CSV/JSON export and import. Data stays in browser local storage; exporting backups is recommended. No PIN security is implemented. An interrupted session saves answered questions when you start a new session or open dashboard, but not necessarily if the app is force-closed.
